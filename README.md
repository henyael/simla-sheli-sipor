# סיפורי שינה נעימים

Create a simple web app in Hebrew for parents.

The app generates bedtime stories for kids.

UI requirements:

- Input field: child's name

- Input field: story topic (free text)
- option  to check if the story is short/ medium/ long
- Sentiments:  Magical/Inspiring/ Learning.
- Button: "צור סיפור"

- Output: display a short bedtime story in Hebrew.

Style:

- clean, calm, bedtime feeling
-  Each page = 2-3 sentences max

- soft colors (blue, purple)

- mobile friendly
- Make it feel like a real parent is telling the story, not an AI.
- Based on the user’s idea
- End with a peaceful, sleepy ending

Logic:

- When user clicks the button, generate a story in Hebrew

- Story should include the child's name

- Tone: calm, magical, suitable for bedtime

- Length: about 3 minutes of reading
- Allow each user to create their own library and save their creations.

Do not require login.
